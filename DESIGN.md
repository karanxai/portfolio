## Brand & Style

This design system embodies high-craft digital engineering, machine intelligence, and high-frequency developer workflows. Designed for a cutting-edge AI engineer and technical creator portfolio, the aesthetic blends refined technical minimalism with futuristic glassmorphism. It creates an aura of computational mastery, deep-space precision, and polished clarity.

The visual direction centers on:
- **Atmospheric Void:** Deep, resonant obsidian and space-navy surfaces that absorb ambient visual noise, allowing critical telemetry, algorithmic benchmarks, and code snippets to glow purposefully.
- **Electric Coherence:** Precision-tuned cyan luminescent highlights that signal high-entropy interactivity, neural status indicators, and key conversion paths without resorting to chaotic neon saturation.
- **Architectural Craftsmanship:** Translucent structural surfaces, sub-pixel edge lighting, hairline grid backdrops, and monospaced telemetry tokens calibrated for absolute developer credibility.

## Colors

The palette operates in a calibrated low-key dark spectrum, establishing intense contrast ratios while minimizing eye fatigue during deep visual inspection.

- **Primary (`#90E6FC`):** An electric computational cyan used exclusively for focused actions, active neural node states, primary CTAs, hover flourishes, and key metrics.
- **Secondary (`#101522`):** Elevated deep navy-black substrate used for intermediate layering, dock panels, and navigation shells.
- **Tertiary (`#263342`):** Structural slate edge tone used for micro-borders, structural dividers, and geometric wireframe guides.
- **Neutral (`#080B12`):** The foundational obsidian canvas, creating an expansive sensory environment.
- **Text Tokens:** `#F5F7FA` ensures AA/AAA compliant high-legibility typographic delivery for core engineering narratives, while `#9CA8B8` governs metadata, framework tags, and secondary documentation.
- **Semantic Accents:** `#E84A5F` serves specialized error tracking, live model aborts, and critical alerts; `#F59E0B` captures telemetry warnings and inference delays.

## Typography

The typographic hierarchy implements a high-performance tri-tier stack:

1. **Display & Headlines (Manrope):** Geometric, precise, and sculpturally balanced. Tight letter-spacing provides a commanding, modern executive weight suited for engineering leadership and architectural showcases.
2. **Body & Interface (Inter):** Highly legible, neutral, and systematically engineered for flawless reading flow in project post-mortems, system descriptions, and technical specifications.
3. **Labels, Meta & Code (JetBrains Mono):** Monospaced typographic punctuation for technical metadata, benchmark parameters, API tags, timestamps, and model latency metrics.

### Scaling & Line Rhythm
Headlines above 32px automatically compress via mobile variant tokens to eliminate awkward word-breaks on smaller viewports. Uppercase treatments are strictly reserved for `label-md` and `label-sm` with deliberate tracking (`0.08em` to `0.1em`) to create an authentic engineering HUD appearance.

## Layout & Spacing

The spatial discipline adheres to an 8px grid cadence with an adaptive fluid-column structure designed for data-dense developer tools and high-impact project showcases.

### Layout Mechanics
- **Desktop (1280px+):** 12-column layout with 24px (`1.5rem`) gutters and a max canvas width of `1240px`. Outer margins sit at `48px` (`3rem`).
- **Tablet (768px - 1279px):** 8-column layout with 20px gutters and 32px margins, collapsing multi-pane telemetry sidebars below hero benchmarks.
- **Mobile (< 768px):** 4-column layout with 16px (`1rem`) gutters and 20px (`1.25rem`) lateral padding margins. Complex split code-comparison panels fold vertically into tabbed surfaces.

### Mathematical Cadence
- `space-xxs` (4px) to `space-xs` (8px): Micro icon offsets, chip inline padding, and dot-indicator spacings.
- `space-sm` (12px) to `space-md` (16px): Standard form element padding, pill chips, and compact list gaps.
- `space-lg` (24px) to `space-xl` (40px): Internal card cushion, modular stack spacing, and card-to-card cluster grids.
- `space-2xl` (64px) to `space-3xl` (96px): Section transitions and contextual hero narrative breaks.

## Elevation & Depth

This design system avoids muddy dropshadows in favor of luminescence, surface opacity tiers, and frosted glass diffraction.

### Depth Hierarchy
- **Level 0 (Canvas Void):** `#080B12` base canvas, overlaid with a subtle, non-distracting 32px radial grid mesh (`rgba(144, 230, 252, 0.03)`).
- **Level 1 (Dock & Structural Rails):** `#101522` at 70% opacity with `backdrop-filter: blur(16px)` and a hairline border of `#263342` (1px solid).
- **Level 2 (Interactive Glass Cards):** `#121A27` at 75% opacity with `backdrop-filter: blur(20px)` and an ambient inner reflection (`inset 0 1px 0 0 rgba(255, 255, 255, 0.06)`).
- **Level 3 (Floating HUD Overlays & Dialogs):** `#121A27` at 92% opacity, supported by a specialized cyan ambient halo (`box-shadow: 0 16px 40px -8px rgba(0, 0, 0, 0.7), 0 0 24px 0 rgba(144, 230, 252, 0.08)`).

### Luminous Edge Treatment
Hover interactions activate dynamic edge lighting: borders transition from `#263342` to an electric gradient containing `#90E6FC` at 60% opacity with a synchronized outer glow (`box-shadow: 0 0 16px rgba(144, 230, 252, 0.2)`).

## Shapes

The geometric personality balances industrial engineering rigor with ergonomic digital tactility. 

- **Primary Geometry:** Base corner radiuses sit consistently at `0.5rem` (8px), signaling clean, purposeful construction.
- **Card Containers (`rounded-lg`):** Scaled to `1rem` (16px) to comfortably wrap dense internal elements while maintaining a sleek, modern outline.
- **Accent Badges & Navigation Docks (`rounded-xl`):** Scaled to `1.5rem` (24px) or full pill geometry (`9999px`) to create distinction between modular data cards and interactive tactile handles.

## Components

### Buttons
- **Primary Cyber:** Solid fill `#90E6FC` with `#080B12` text in `Inter` semi-bold. On hover: shifts brightness, projects an outer luminous halo (`0 0 20px rgba(144, 230, 252, 0.4)`), and lifts by `-1px`.
- **Secondary Ghost Glass:** Background `#121A27` (60% alpha), 1px border `#263342`, text `#F5F7FA`. On hover: border tints to `#90E6FC`, text illuminates to `#90E6FC`, and background shifts to `#101522`.
- **Terminal Icon Button:** Square 40x40px or 36x36px frame, `#101522` background, hairline `#263342` border, with centered SVGs rendered in `#9CA8B8` (turning `#90E6FC` on hover).

### Badge Chips & Tags
- **Model Status / Stack Chips:** Rendered in `JetBrains Mono` at `label-sm` with pill geometry (`rounded-full`). Background is `rgba(16, 21, 34, 0.8)` with a 1px border of `#263342`.
- **Active State:** Features a pulsating green or electric cyan 6px circular node indicator (`box-shadow: 0 0 8px #90E6FC`).

### Glass Cards
- Built on `#121A27` with 80% opacity, `backdrop-filter: blur(16px)`, and 1px border `#263342`.
- Padding conforms strictly to `space-lg` (24px).
- Internal dividers utilize hairline borders of `#263342` with 50% opacity.

### Input Fields & Terminal Prompts
- Background `#101522`, border 1px solid `#263342`, text `#F5F7FA`, placeholder `#9CA8B8` at 60% opacity.
- Focused state: Border transitions instantly to `#90E6FC` accompanied by a localized focus ring (`0 0 0 2px rgba(144, 230, 252, 0.2)`). Monospaced prompt prefixes (`$`, `>`) default to `#90E6FC`.

### Checkboxes & Radios
- Square / circular frames in `#101522` with a 1.5px `#263342` perimeter.
- Checked state: Fill switches to `#90E6FC` with an obsidian `#080B12` checkmark icon and a soft radiant cyan glow.

### Interactive Code / Telemetry Blocks
- Custom developer showcase container featuring a top header rail with three muted status dots (`#263342`, `#9CA8B8`, `#90E6FC`) and an active branch label in `code-sm`.
- Background set to solid `#0A0E18` to prioritize syntactic scan-speed with custom syntax-highlighting matching the cyan-slate-crimson spectrum.
